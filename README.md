

##### **Computer Networks Final Project - TCP/IP Analysis \& Chat Application**



**Course:** Computer Networks

**Group:** 02 

**Project Overview**

This repository contains the final project for the Computer Networks course, divided into two main parts:

1\.  **Part 1:** Data encapsulation, CSV generation, and traffic analysis using Wireshark and Jupyter Notebook.

2\.  **Part 2:** Implementation of a multi-client Chat System using Python Sockets (TCP) and analyzing its traffic.



**Repository Structure**

**Part1\_PacketAnalysis:** Contains the CSV input, the executed Jupyter Notebook, and the Wireshark capture file (.pcap).

**Part2\_ChatApplication:** Contains the Server and Client Python scripts and the traffic capture file.

**Report:** Contains the detailed documentation for both parts (split into two PDFs).
